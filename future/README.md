# `future/` — forward-looking ideas

This folder catalogs proposed enhancements, bug-fix epics, and
capability extensions that are **not yet planned, scoped, or
committed** to the roadmap. Treat each idea as a discussion seed —
not a contract.

If an idea progresses to a real plan, **move it** to `docs/plans/`
with a date-prefixed filename and remove or annotate the entry here.

## What's in here

| File | Contents |
|---|---|
| `IDEAS.md` | 10 starter ideas — capability, UX, reliability, security, and DX |

## Conventions

- Each idea is self-contained with: motivation, sketch, dependencies,
  risk, and a rough effort estimate (T-shirt: S / M / L / XL).
- Don't delete ideas that are rejected — annotate with `**Rejected: <reason>**`
  so the decision is recoverable.
- Don't put credentials, customer data, or anything operationally
  sensitive in here.
