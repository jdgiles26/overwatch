Below is a concise summary of what I built, what the science says, and what an operator actually sees.

The Problem

Commercial drones (sub-$500, multi-kilogram payload capacity) represent a rapidly growing threat in both civilian and operational contexts — reconnaissance, payload delivery, communications relay, and coordinated swarm attacks. Traditional radar is impractical at close range: minimum engagement distances, active emissions that expose the sensor, and poor performance against low-altitude slow-moving targets. Commercial drone-detection systems (Dedrone, Aaronia, Fortem) cost $50,000–$500,000 per installation, require proprietary cloud connectivity, and cannot be natively integrated into a unified command picture.

What I Built

A fully passive drone detection, tracking, and threat-classification module — integrated directly into the OverWatch situational-awareness platform. No active radar emissions. No cloud dependency. Detection data appears in the same Intel feed, triggers the same alert rules, and affects the same THREATCON score as every other intelligence source in the system.

this is the meat:
Two ground-based antennas — a reference transmitter (e.g., a WiFi access point or dedicated beacon) and a receiver node — maintain a known RF corridor between them. When a drone flies through that corridor, its airframe and spinning propellers perturb the radio channel in a measurable way: its blades produce a characteristic micro-Doppler sideband pattern in the frequency spectrum — a fingerprint unique to drone flight. The receiver node reports this disturbance. No camera, no active radar pulse, no acoustic sensor. The drone does not need to emit anything to be detected; the detection is purely a consequence of it disturbing the signal between two fixed antennas.

4. Technology Significance: Why is WiDFS 3.0 Innovative?

WiDFS 3.0 improves upon traditional radar by combining highly-efficient signal processing and Integrated Sensing and Communication (ISAC) algorithms into a portable, edge-ready framework. It achieves comparable resolution and motion tracking using just one transmitter and one receiver, massively reducing hardware complexity.

The Core Innovations:

  • Lightweight Sensing Architecture (SISO): Contrasts heavily with multi-antenna phased array radars or MIMO systems. Operates with one transmit and one receive antenna.
  • Self-Referencing Cross-Correlation (SRCC): Solves the clock asynchrony problem in bistatic sensing. Removes random phase offsets using a reference signal derived from distorted CSI, enabling precise motion detection without strict hardware synchronization.
  • Delay-Doppler-Based Processing: Extracts distance and velocity information to determine speed, heading, and altitude with high resolution.
  • Compact Neural Network: Integrates MobileViT XXS, allowing real-time motion classification on embedded, low-power systems like the Raspberry Pi or NVIDIA Jetson Nano.

The underlying science is independently peer-reviewed. The Ilmenau University of Technology group (Costa et al.) has published four validated experimental studies — IEEE RadarConf24 (2024), IRS Wroclaw (2024), IEEE JSTEAP (2025), GeMiC (2025) — demonstrating that OFDM communication signals produce discriminative micro-Doppler signatures from commercial drone propellers with ~0.98 model-to-measurement correlation. A fifth field study (Demissie et al., IET Radar 2025) validated LTE-based passive radar drone detection at ~200 m range in outdoor conditions.

Open-source signal-processing foundations exist: pyapril (pip-installable Python passive radar DSP library) and passive-sdr-radar (Docker, KrakenSDR + Pi pipeline, hardware integration in active development).

What Makes This Different

  • Fully passive — no active radar emissions, no exposure of sensor position
  • On-premises, no cloud — inference runs in a browser Web Worker; detection data never leaves the operator's network
  • Unified picture — drone events appear in the same feed, trigger the same alerts, and feed the same THREATCON score as OSINT, ADS-B, computer vision, and seismic events — operators don't switch tools
  • Swarm detection — heading/speed vector correlation across simultaneous tracks identifies coordinated swarm activity
  • AI threat classification — on-device Web Worker scores each track for evasion, loiter, descent rate, and payload stability; labels each track hostile / neutral / unknown in <50 ms
  • Cost — 6-node passive-intercept perimeter under $500 vs. $100,000+ for commercial radar

What the Operator Sees

The map plots a position estimate for each RF-detected object — the system's best guess of where the drone is, derived from signal strength and Doppler data at the ground nodes, not from a camera or optical sensor.

  • Quad-rotor icon on the operational map, colour-coded by AI threat classification: cyan = unknown, orange = neutral, red = hostile
  • Solid trail = positions while the node is actively receiving signal disturbances; dashed trail = coasting (position dead-reckoned forward after the signal drops)
  • Ellipse range ring showing the uncertainty radius around the estimated position
  • 30-step dead-reckoning prediction arc — where the drone is heading if it maintains current speed and heading
  • Confidence cone showing the spread of that prediction based on track quality
  • Detail HUD: aggression score, 5 behavioural sub-scores (evasion, loiter, descent rate, payload stability, swarm flag), 60-second history sparkline, raw RF payload
